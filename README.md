## v4.8.2 — 3유파 독립 진화 및 일시정지 원정 도감

- 3개의 일반 무공 슬롯을 최대 3개의 **유파 슬롯**으로 재정의. 각 유파의 무공 2종과 핵심 심법 1종을 해당 유파 안에서 수집
- 조건 충족 시 기존 `v39TryAutoFusion()` 전투 로직을 이용해 자동 진화, 재료 3종을 진화 무공 1종으로 합침
- 여러 유파를 동시에 키울 수 있고, 최대 3개 유파가 각자 상위 무공으로 진화할 수 있음
- 매번 상자 보상으로 재료 확보 / 새 유파 선택 / 보유 무공 강화 / 캐릭터 능력 수련 가운데 선택
- 일시정지 화면 4개 탭: 캐릭터 현재 능력치, 착용 장비 및 가방 아이템(조회 전용), 보유 유파별 3종 재료 수집률, 6종 전체 진화 공식
- 오른쪽 하단에는 3개 유파의 성장 상태(빈 슬롯 / 1~3 재료 / 진화 완료)를 항상 표시
- 기존 v4.8.1 진행 중 체크포인트를 불러오면 보유 무공과 기존 유파를 가능한 범위에서 이어받음. 기존 계정 장비와 문파 성장 구조는 변경하지 않음
- 새 JS/CSS `js/build-v482.js` / `css/build-v482.css`, Service Worker 캐시 `murim-survival-v4-8-2-pwa-1`
- 적의 발사체 시인성 개선은 v4.8.1 방식 유지. iPhone 실기 성능은 별도 사용자 테스트 필요

**시험:** 새 원정의 첫 상자를 파괴해 유파 선택 → 서로 다른 유파를 최대 3개 개방 → 한 유파의 추가 재료 2종을 수집해 자동 진화 확인 → 3개 유파 모두 진화 가능한지 확인 → 일시정지에서 능력 / 장비·가방 / 유파 / 진화 도감 탭 순차 확인 → 앱 재시작 후 원정 복구 검증.

## v4.8.1 - Martial Path Strategy & Hostile Bullet Readability

- 첫 보급 상자에서 6개 유파 중 무작위로 제시되는 3개 유파 중 1개 선택
- 초반 첫 3개 상자에서는 무공 선택 기회 보장; 이후 상자는 기존 무공 보상 확률 유지
- 유파별로 기존 융합 비급과 실질적인 성장 보너스 차별화(화력·무공 재사용·체력·회복·치명타·이동속도)
- 하나의 원정에서 최대 3개 무공 운용, 보급 상자 보상으로 관련 무공·강화·보조 무공·수련 보너스 중 직접 선택
- 이미 3칸을 사용 중이면 기존 무공 교체 여부와 희생할 무공을 직접 선택
- 선택한 유파의 핵심 심법만 보상에서 등장하므로 모든 무공을 무제한 수집하는 방식 종료
- 3개의 필수 무공을 확보하면 기존의 융합 시스템을 통해 고유 상위 무공 활성화
- 전투 오른쪽 하단에 선택한 유파와 실제 무공 3칸·레벨 표시
- 적 발사체를 검은 외곽, 붉은 몸체, 상아색 중심부로 구별. 방향성 꼬리 추가
- 보스 장판 경고를 검은 테두리와 밝은 노란색 선으로 구별
- 모바일 프레임 유지를 위해 추가 블러·그라디언트·이미지 자산 없이 단순 Canvas 경로만 사용
- v4.8.0 체크포인트 구조를 유지하며 플레이어 상태에 유파/선택지 메타데이터 저장
- JS: `js/build-v481.js`, CSS: `css/build-v481.css`, PWA 캐시: `murim-survival-v4-8-1-pwa-1`

**테스트 안내:** 신규 원정을 시작하여 첫 상자 파괴 → 유파 선택 → 이후 상자에서 무공 3칸 제한/강화/교체 확인 → 적의 원거리 탄환과 보스 경고 시인성 확인. 기존 v4.8.0에서 저장된 진행 중 원정은 기존 능력을 유지할 수 있으므로 새 원정에서 제한을 검증합니다.

- 본거지 BGM
- 청죽림 BGM
- 설봉고도 BGM
- 적벽협곡 BGM
- 고묘지궁 BGM
- 보스 BGM
- 검/비도/철궁/백우선/철추/장창/쌍월륜/검부 효과음
- 피격/강타
- 상자 타격/파괴
- 아이템 획득/희귀 획득
- 승리/실패
- UI 클릭

메인 화면의 `🎵 소리 설정`에서 전체/배경음악/효과음 음량 및 ON/OFF를 조절할 수 있습니다.
