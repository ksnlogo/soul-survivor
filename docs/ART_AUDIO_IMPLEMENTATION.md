# 무림 생존록 Art & Audio Implementation Spec — v4.5

## Vertical Slice acceptance criteria

### 가독성
- 플레이어는 일반 적보다 화면 표시 크기가 약간 크거나 동일하며 보스보다 확실히 작아야 한다.
- 플레이어/제자/적은 실루엣만으로 구분되어야 한다.
- 일반 적 HP바는 숨기고 정예/호법/장문인만 표시한다.
- 전투 이펙트가 플레이어 중심 35% 이상의 화면을 지속적으로 덮지 않는다.

### 청죽림
- 배경은 캐릭터보다 낮은 채도와 명도를 유지한다.
- 산세/운무/대나무를 최소 3개 깊이 레이어로 표현한다.
- 월드 오브젝트는 전투 판정 오브젝트와 시각 장식을 명확히 구분한다.

### 사운드
- BGM은 효과음보다 약하게 들려야 한다.
- 같은 공격음이 빠르게 반복될 때 중첩을 제한한다.
- 보스 등장, 상자 파괴, 희귀 아이템 획득은 일반 공격보다 명확한 피드백을 준다.
- 첫 사용자 입력 전에는 오디오 자동 재생을 시도하지 않는다.

### 모바일 성능
- 390x844 기준 iPhone Safari에서 프레임 저하가 체감되지 않아야 한다.
- Canvas 외부 이미지 자산을 도입할 때 한 화면에서 필요한 이미지만 사용한다.
- BGM은 전부 선캐시하지 않고 최종 음원 단계에서 런타임 캐시로 전환한다.

2. 서진
