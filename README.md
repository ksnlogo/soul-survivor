# 무림 생존록 v4.7.1 — Cohesive Stage Environments

v4.4.2 안정판을 기준으로 **게임 구조를 유지하면서 아트/사운드 레이어를 실제 개발 구조로 분리한 첫 Vertical Slice**입니다.

## 이번 버전의 목표

1. 거대한 단일 `index.html` 구조를 CSS/JS 파일로 분리
2. Web Audio 기반 BGM/SFX 엔진 추가
3. 청죽림을 기준으로 플레이어·적·제자·상자·배경의 무협 실루엣 강화
4. 소리 설정 UI 추가
5. 외부 이미지/음원을 대량 투입하기 전에 모바일 성능과 분위기 검증
6. 제자 숙소 Lv.0에서는 실제로 제자 0명, Lv.1~5에서 순차 해금되도록 재확인

## 파일 구조

```text
index.html
css/game.css
js/audio.js
js/game.js
js/graphics-v461.js
js/art-assets-v471.js
js/integration.js
assets/art/
assets/audio/
manifest.webmanifest
service-worker.js
icons/
```

## Audio Vertical Slice

외부 음원 없이도 기기에서 바로 검증할 수 있도록 Web Audio API를 이용한 경량 합성 오디오를 적용했습니다.

- 본거지 BGM
- 청죽림 BGM
- 설봉고도 BGM
- 적벽협곡 BGM
- 고묘지궁 BGM
- 보스 BGM
- 검/비도/철궁/백우선/철추/장창/쌍월륜/검부 효과음
- 피격/강타
- 상자 타격/파괴
- 아이템 획득/희귀 획득
- 승리/실패
- UI 클릭

메인 화면의 `🎵 소리 설정`에서 전체/배경음악/효과음 음량 및 ON/OFF를 조절할 수 있습니다.

## 테스트 우선순위

1. iPhone Safari에서 최초 터치 후 BGM이 시작되는지
2. 스테이지 시작 시 현재 맵에 맞는 BGM으로 전환되는지
3. 청죽림에서 플레이어/적/대나무/상자가 이전보다 구분되는지
4. 공격 효과음이 너무 자주 겹쳐 시끄럽지 않은지
5. 숙소 Lv.0에서 동행 제자가 0명인지
6. 숙소 Lv.1에서 서진이 처음 해금되는지
7. 프레임 저하가 없는지
8. PWA 재실행 시 음량 설정이 유지되는지

## 다음 단계

이 Vertical Slice의 방향이 적절하면 절차형 아트를 실제 제작 스프라이트로 순차 교체합니다.

우선순위:
`청운문 주인공 → 서진 → 일반 적 4종 → 청죽림 타일/오브젝트 → 상자 → 핵심 무기 이펙트`

실제 BGM도 같은 방식으로 최종 음원으로 교체할 수 있도록 `assets/audio/` 슬롯을 마련해 두었습니다.

## v4.5.4 성능 최적화 + 전투 타격감 폴리싱
- 모바일 Canvas DPR 2.0 → 최대 1.5로 조정하여 픽셀 처리량 감소
- 최대 월드 적 220 → 180으로 조정하되 주변 적 밀도 유지 로직은 그대로 유지
- 화면에서 멀리 떨어진 일반 적은 매 프레임 AI/장애물 충돌 계산을 수행하지 않음
- 투사체 충돌에 broad-phase를 추가하여 불필요한 정밀 거리 계산 감소
- HUD 12fps, 미니맵 약 5.5fps, 웨이브 UI 약 8fps로 갱신 제한
- 동일 지역의 zone/enemy 안내 DOM을 매 프레임 다시 쓰지 않도록 수정
- 파티클/공격 이펙트 상한을 적용해 대규모 교전 시 GC spike 방지
- SFX를 첫 전투 중 지연 생성하지 않고 메뉴에서 idle preload
- 효과음 동시 재생 상한 7개, 일반 피격음 우선순위 제한
- 검/철추/창의 휘두름·찌르기 모션 추가
- 적 피격 순간의 짧은 백색 플래시·교차 스파크 추가
- 근접 공격에 미세 넉백, 회심/철추/대형 무공에 카메라 흔들림 추가
- 강한 공격만 순간 화면 플래시를 사용하고 일반 타격에는 hit-stop을 사용하지 않아 끊김과 혼동되지 않도록 설계
- 실제 공격/스킬이 생성된 경우에만 해당 효과음을 재생하도록 타이밍 보정
