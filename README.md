# 무림 생존록 v4.4.1 - 강호 상단 장비 테마 정리

- 상점 원본 데이터에 남아 있던 판타지형 `지팡이/마법서/해머/도끼` 명칭과 아이콘을 제거했습니다.
- 무기군을 청강검 / 비도 / 철궁 / 백우선 / 철추 / 장창 / 쌍월륜 / 검부로 통일했습니다.
- 방어구와 장신구의 이름·아이콘을 도건, 장포, 도복, 완갑, 행전, 옥패, 부적 등 무협 장비 체계로 정리했습니다.
- `룬·심연·세계수·종말` 등 판타지 등급 접두어를 무협식 접두어로 교체했습니다.
- 옵션 명칭도 강기 / 연환 / 파혈 / 경공 / 금강 / 운기 / 재운 등 무협식으로 변경했습니다.
- 상점은 병장기 1 + 방어구 2 + 장신구 1 + 고급 추천 1의 기본 구성을 갖도록 변경했습니다.
- 아직 비어 있는 방어구 슬롯을 상점이 우선 제안하도록 하여 초기 장비 성장을 부드럽게 만들었습니다.
- 기존 저장 데이터의 능력치와 진행도는 유지하고, 기존 상점 재고만 최초 1회 무료 갱신합니다.

# 무림 생존록 v4.4.0

## 현장 플레이 피드백 반영

- **상자 크기 축소**: 일반/강화/보스 보상 상자를 플레이어와 적 비율에 맞게 약 9~14px 반경으로 재조정했습니다.
- **상자 파괴 보장**: v4.1.5에서 근접 공격 판정 조정 과정에 빠졌던 검/철추/장창의 상자 피해를 복원했습니다. 상자 가까이 접근하면 자동 공격이 상자를 보조 타격하므로 시작 무기만으로도 파괴 가능합니다.
- **동행 제자 시스템**: 제자는 더 이상 플레이어 능력치 프리셋이 아닙니다. 전투 전 한 명을 선택하면 실제 필드에 함께 들어와 플레이어를 따라다니며 공격/치유합니다.
- **초기 제자 0명**: 새 시작 및 제자 숙소 Lv.0에서는 동행 제자가 없습니다. 숙소 Lv.1~5에서 서진 → 연화 → 무진 → 태산 → 소연 순으로 해금됩니다.
- **HUD 간소화**: 처치 수/전투 중 금화는 상시 HUD에서 숨기고, 지역/적 안내/무기명/부가 임무 상세는 시작 또는 변화 시 잠시 표시 후 사라집니다. 미니맵도 축소했습니다.
- **전 맵 적 개체군**: 스테이지 시작 시 맵 전체에 적을 분산 배치하고, 플레이어가 멀리 이동했을 때 주변 적이 비면 멀리 떨어진 일반 적을 재배치해 전투 밀도를 유지합니다.
- **기존 데이터 유지**: 장비, 금화, 스테이지, 문파 공헌, 건물, 비전은 유지됩니다. 기존 선택 제자가 현재 숙소 레벨보다 높으면 자동으로 동행 해제됩니다.

## 점검 권장 항목

1. 수련용 청강검으로 일반 보급 상자를 2~3초 내 파괴할 수 있는지
2. 제자 숙소 Lv.0에서 동행 제자가 `없음`으로 표시되는지
3. 숙소를 올린 뒤 해금된 제자를 선택하면 전투에서 실제로 따라다니는지
4. 지역/임무 안내가 몇 초 뒤 사라져 전투 시야를 가리지 않는지
5. 맵 끝이나 먼 지역으로 이동해도 주변에 적이 지속적으로 나타나는지

# 무림 생존록 v4.3.0

v4.2.0의 현대 무협 그래픽을 유지하면서 장기 진행 시스템을 확장한 버전입니다.

## 핵심 추가 시스템

- **랜덤 부가 임무**: 매 원정마다 깃발 파괴, 제자 구출, 비급 회수, 약초 채집, 강호 고수 토벌 중 1개가 생성됩니다.
- 부가 임무 완료 시 **문파 공헌 + 문파 명성 + 보상 상자**를 획득합니다.
- **청운문 본거지**: 연무장, 장경각, 대장간, 약방, 제자 숙소를 최대 Lv.5까지 성장시킬 수 있습니다.
- **문파 공헌**: 스테이지 클리어와 부가 임무로 얻으며 건물 성장에 사용합니다.
- **전투 제자 선택**: 검수, 암기수, 창수, 권사, 의원 중 한 명을 선택하며 제자 숙소 레벨에 따라 해금됩니다.
- **문파별 고유 비전**: 매 5번째 문파전 승리 시 상대 문파의 영구 비급을 획득합니다. 같은 문파를 다시 격파하면 최대 Rank 3까지 강화됩니다.
- 문파 비전, 건물, 전투 제자 효과는 모든 이후 스테이지에 영구 적용됩니다.

## 본거지 건물 효과

- 연무장: 공격력 +4% / Lv.
- 장경각: 경험치 획득 +6% / Lv.
- 대장간: 상점 구매가 -3% / Lv.
- 약방: 최대 HP +4%, 체력 물약 효과 +6% / Lv.
- 제자 숙소: 이동속도 +2% / Lv., 새로운 전투 제자 해금

## 전투 제자

- 검수 서진: 검·창·철추 계열 피해 +10%
- 암기수 연화: 비도·철궁·쌍월도 피해 +12%, 치명타 +4%
- 창수 무진: 장창 피해 +18%, 이동속도 +6%
- 권사 태산: 최대 HP +12%, 피해 감소 +4%
- 의원 소연: 초당 회복 +0.45, 체력 물약 효과 +30%
