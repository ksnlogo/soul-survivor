# 무림 생존록 v4.4.2 — 코드 정리 및 무협 세계관 통합판

v4.4.2는 새 기능을 추가하지 않고, v4.4.1까지 검증된 기능을 유지하면서 코드와 세계관 데이터를 정리한 안정화 버전입니다.

## 이번 정리의 핵심

- 아이템 원본 데이터를 무협 장비 체계로 직접 통합했습니다. 실행 뒤 덮어쓰는 판타지 장비 원본을 제거했습니다.
- 병장기는 청강검 / 비도 / 철궁 / 백우선 / 철추 / 장창 / 쌍월륜 / 검부로 통일했습니다.
- 방어구·장신구 원본도 도건, 장포, 도복, 완갑, 행전, 답설화, 옥패, 부적 등 무협식으로 통일했습니다.
- 세트 장비를 `유영비갑 / 금강호갑 / 청명운문`으로 통일했습니다.
- 장비 옵션명은 강기 / 연환 / 파혈 / 장력 / 경신 / 호체 / 금강 / 운기 / 경공 / 탐물 / 재운 등으로 통일했습니다.
- 맵과 적의 기본 데이터도 청죽림 / 설봉고도 / 적벽협곡 / 고묘지궁, 외문 무사 / 경공 자객 / 철포삼 고수 / 암기수 / 패도 무사 / 내문 고수 / 호법 / 장문인으로 통일했습니다.
- 스킬·핵심 심법·융합 절기의 원본 명칭을 무협식으로 정리했습니다.
- 구형 `runWeaponLevel`, `evolutionReady`, `evolveWeapon`, 무기 숙련 레벨업 선택 코드를 제거했습니다. 현재 레벨업은 스킬 강화와 기본 능력 강화만 제공합니다.
- `READY / CRIT / SHIELD / STAGE CLEAR` 등 일부 영문 전투 문구를 `준비 / 회심 / 호신 / 원정 성공`으로 정리했습니다.
- v4.4.1에서 별도 패치로 붙었던 상점 원본 수정은 현재 무협 데이터 기준의 단일 상점 모듈로 정리했습니다.
- 기존 저장 데이터는 유지하며, 이전 판타지 무기 스냅샷은 최초 1회 현재 무협 명칭으로 보정합니다.

## 현재 게임 구조

### 원정
- 1~4 스테이지: 청운문 성장 원정
- 매 5번째 스테이지: 경쟁 문파와 문파전
- 기본 목표: 7분 생존 + 중간/최종 보스
- 랜덤 부가 임무: 깃발 파괴 / 제자 구출 / 비급 회수 / 약초 채집 / 강호 고수 토벌
- 전 맵 적 개체군 + 현재 지역 전투 밀도 보충

### 전투·파밍
- 신규 시작 장비는 `수련용 청강검` 1개뿐입니다.
- 보급/보상 상자는 무기로 파괴합니다.
- 상자에서는 장비, 회복 단약, 무공, 금화를 획득할 수 있습니다.
- 장비 획득 시 전투가 일시정지되고 현재 장비와 비교 후 장착 / 보관 / 버리기를 선택합니다.
- 장신구는 3슬롯 중 장착 위치를 직접 선택합니다.
- 전투 무공은 상자에서 발견하며 획득 즉시 자동 발동합니다.
- 일반 무공 + 지정 핵심 심법/기물 조합으로 상위 절기가 자동 융합됩니다.

### 청운문 성장
- 자원: 금화(개인 장비/상점) + 문파 공헌(본거지 성장)
- 본거지: 연무장 / 장경각 / 대장간 / 약방 / 제자 숙소
- 제자 숙소 Lv.0에서는 동행 제자가 없습니다.
- 숙소 Lv.1~5에서 서진 → 연화 → 무진 → 태산 → 소연 순으로 해금됩니다.
- 원정 전 해금된 제자 중 한 명을 선택할 수 있으며 실제 필드에서 플레이어를 따라다니며 보조 전투를 수행합니다.
- 매 5번째 문파전 승리 시 경쟁 문파의 고유 비전을 영구 획득/강화합니다.

### 화면·그래픽
- 현대 무협풍 산세, 운무, 대나무 잎, 눈발, 불씨 등 지역별 환경 효과
- 플레이어/적/공격 판정의 모바일 비율 조정
- 지역·적 안내·무기명·부가 임무 상세은 필요할 때 잠시 표시 후 자동으로 사라집니다.
- 축소형 미니맵을 유지합니다.

## 상점

기본 재고는 다음 구성을 우선합니다.

- 병장기 1
- 방어구 2
- 장신구 1
- 고급 추천 장비 1

비어 있는 방어구 슬롯이 있으면 해당 부위를 우선 추천합니다. 무공은 상점에서 판매하지 않고 전투 중 상자에서만 발견합니다.
