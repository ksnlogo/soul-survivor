# 무림 생존록 v4.1.4 - 무기 단독 시작

- 신규 게임은 **수련용 청강검 1개만** 보유·장착한 상태로 시작합니다.
- 머리 / 갑옷 / 장갑 / 하의 / 신발 / 장신구 3칸은 모두 빈 슬롯입니다.
- 기존 테스트 저장 데이터에 남아 있는 기본 지급 수습 방어구와 낡은 부적은 최초 1회 자동 제거합니다. 직접 획득한 장비는 유지합니다.
- 무기 숙련 표시는 UI에서 완전히 제거했습니다. 현재 활성 레벨업 시스템에는 무기 숙련 선택지가 없으며 무기는 등급·옵션·전투력으로 비교합니다.
- 기존 진행 스테이지 / 문파 명성 / 금화 / 획득 장비 / 발견 무공은 유지합니다.
- PWA 캐시를 v4.1.4로 갱신했습니다.

# 무림 생존록 v4.1.3 - 시작 오류 핫픽스

- Safari에서 스테이지 시작 시 `weaponMastery` 요소가 `null`이 되어 실행이 중단되던 원인을 수정했습니다.
- v4.0 무협 UI 패치가 `weaponBadge.innerHTML`을 다시 만들면서 숨겨진 `weaponMastery` 요소를 삭제한 것이 원인이었습니다.
- 해당 요소를 유지하고, 레거시 무기 숙련 표시 코드에도 null-safe 방어 처리를 추가했습니다.
- PWA 캐시 이름을 v4.1.3으로 갱신했습니다.

# 무림 생존록 v4.0 - 설치형 PWA

몰락한 **청운문**을 다시 일으키는 무협 생존 액션 RPG 버전입니다.

## v4.0 핵심 변경

- 게임 전체 세계관을 다크 판타지에서 **무협 / 강호 / 문파 성장** 콘셉트로 전환
- 1~4 스테이지: 산문 수복 → 영맥 확보 → 제자 규합 → 비급 회수
- 매 5번째 스테이지: 경쟁 문파 총단을 공격하는 **문파전**
- 문파전 상대: 흑풍문 → 적월방 → 철산파 → 독룡곡 → 천마련 순환
- 문파 명성 시스템 및 문파 등급 표시
- 문파전 장문인은 일반 최종 보스보다 체력·공격력이 강화됨
- 기존 랜덤 맵을 무협 테마인 청죽림 / 설봉고도 / 적벽협곡 / 고묘지궁으로 변경
- 무기·장비·적·스킬 명칭을 무협 세계관에 맞게 변경
- 스킬은 `무공`, 핵심 스킬은 `심법/기물`, 융합 스킬은 `절정 무공` 콘셉트
- **스테이지 클리어 후 처음 상점(강호 상단)에 입장할 때 상품 자동 갱신**
- 수동 리로드 기능은 기존처럼 유지
- 기존 장비/골드/진행 저장 데이터와 호환
- PWA 오프라인 캐시 버전을 v4.0으로 갱신

## 진행 구조

1. 원정에서 상자를 파괴해 장비와 무공 획득
2. 강적과 보스를 처치하며 문파 명성 축적
3. STAGE 1~4에서 청운문의 기반 확장

## v4.1 경제 밸런스 조정

- 일반 몬스터 처치 시 문파 자금이 더 이상 확정 드롭되지 않습니다.
- 적 종류에 따라 약 4~28% 확률로 소량의 자금이 드롭됩니다. 중간/최종 보스는 직접 금화를 주기보다 보상 상자를 제공합니다.
- 일반 보급 상자도 금화가 확정되지 않으며, 상자 등급이 높을수록 자금 드롭 확률과 양이 증가합니다.
- 기존의 `처치 수 × 2 + 생존 시간` 기반 대량 골드 지급을 제거했습니다.
- 일반 스테이지 클리어 보상은 소량의 고정 문파 자금, 문파전은 그보다 높은 고정 보상을 제공합니다.
- 상점 장비 가격을 등급에 따라 상향했습니다. 대략 일반 < 희귀 < 영웅 < 전설 < 신화 순으로 구매 부담이 명확해집니다.
- 장비 판매가는 상점 구매가의 약 24%로 낮춰 되팔이를 통한 자금 증식을 방지했습니다.
- 상점 수동 리로드 비용은 50부터 시작하며 같은 스테이지에서 반복할수록 35씩 증가합니다.
- 인벤토리/전투 가방 초과 시 자동 환전 금액도 크게 줄였습니다.

목표 경제 흐름은 `전투 중 소량 획득 → 스테이지 클리어 보너스 → 몇 스테이지에 걸쳐 자금 축적 → 필요한 장비를 선별 구매`입니다.
- 기존 버전에서 이미 과도하게 누적된 문파 자금은 v4.1 최초 실행 시 현재 진행 스테이지에 맞는 상한으로 1회 보정됩니다. 보유 금액이 상한보다 낮으면 줄어들지 않습니다.
